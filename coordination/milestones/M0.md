# M0 — Process foundation

## Outcome

A working coordination machine and a product repository whose quality claims are verifiable
by someone who did not write the code. No game feature work belongs to this milestone.

## Why this milestone exists

The previous process (`docs/superpowers/`) produced 2.03 MB of Markdown against 1.44 MB of
Rust, of which roughly a quarter still describes the current tree. Its seven failure modes were
all missing *mechanisms*, not lapses of diligence: no gate forced a doc to change when the code
changed, artifacts had no identity outside the session that made them, the status vocabulary
had no terminal state, and a mandated checkbox convention ran at 0/1531 compliance for three
months. Every AR below installs one of the mechanisms that makes that recurrence impossible.

## Restart

M0 was completed while coordination ran from a separate repository. When the project was
published, that history was not carried over and the task set restarted from empty; this
document is kept so the series stays governed and the record of what M0 delivered stays next to
the tool. [HISTORY.md](../HISTORY.md) records each of AR-0001 to AR-0018. Paths below are as they
were then: `tools/handoffctl` is now `coordination/tools/handoffctl`, and `docs/superpowers/` is
the deleted corpus criterion 5 refers to.

## Exit criteria

Each is falsifiable by a command; a claim without a recorded exit code does not count.

1. `tools/handoffctl doctor --live` passes, and the coordinator's own quality sequence
   (ruff, strict mypy, 38+ fault tests, >=95% branch coverage, schema, `render-status --check`)
   passes both locally and on GitHub Actions.
2. `tools/quality/run-gates.sh <SHA>` runs to completion on a clean checkout of
   `game-experiment` `main`, from a hermetic worktree, and every gate passes.
3. Every gate in that runner is **proven able to fail**: the negative-fixture suite plants a
   defect for each one and records the rejection.
4. `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings` and
   `cargo test --workspace` are all green on `main` with no suppressions carried forward.
5. `docs/superpowers/` no longer exists, and no link anywhere in the tree is dangling.
6. `CLAUDE.md` and the architecture index describe the crates that actually exist.
7. Every AR in series 00 is `done`, with its evidence recorded in its task.

## Out of scope

Deliberately deferred to M1 and later, so that this milestone can finish:

- Physics-invariant property tests (energy / momentum / angular-momentum drift, Kepler and
  L-point analytic checks) and the determinism gate.
- Promoting the CPU-vs-GPU differential oracle to a required gate.
- Criterion performance budgets for the accelerator.
- Structurally enforcing the "at most one writer per slot" invariant that 17 `unsafe` blocks
  in the world storage currently rest on. **This is the highest-consequence open risk in the
  repository** and is the leading candidate to open M1.
- The two `FIXME: deadlock?` sites in the implicit solver, and their ignored reproducers.
- Any renderer, input layer, scene layer or game content.
