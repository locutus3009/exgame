# M1 — Accelerator completion

## Outcome

Everything `ACCELERATOR.md` describes as designed but not built, and every place where it
claims more than the code does, is either implemented or explicitly retired with a reason.
When the series is done, `ACCELERATOR.md` is deleted and nothing in the tree points at it.

The starting point is an item-by-item audit of the document against the code at `4d5b23c`.
It found that the document is wrong in both directions: block copies and the finiteness probe
it lists as host work are already GPU messages, while Vulkan failures it says come back as
`EvalError::Backend` actually panic the worker, and writing past World's fixed capacity is
undefined behaviour rather than an error.

## Exit criteria

Each is falsifiable by a command; a claim without a recorded exit code does not count.

1. `cargo test --workspace --release` exits 0 on `main`, and the two tests ignored with
   `FIXME: deadlock?` run without `#[ignore]`.
2. A test inserts past World's initial per-type capacity and the stored values survive the
   growth; a GPU dispatch after growth reads the grown buffer.
3. A test plants two writers on one output slot in one batch and the accelerator refuses the
   batch instead of dispatching it.
4. A test makes the Vulkan submission fail and the caller receives `EvalError::Backend`, not
   `WorkerGone`.
5. A test steps several mechanisms through the epoch driver, and a structural mutation
   attempted mid-epoch is refused.
6. `git ls-files ACCELERATOR.md` prints nothing and `python3 tools/quality/check_docs.py`
   exits 0.
7. Every AR in series 01 is `done`, `cancelled` or `superseded`, with its evidence recorded.

## Out of scope

Design prose in `ACCELERATOR.md` that the project has since decided against. Each is retired,
not deferred:

- The bespoke `GpuVec<T>` over raw `ash` and its sub-allocated pool. Storage is a vulkano
  `Subbuffer`, and no first-party crate depends on `ash` (CLAUDE.md, "Graphics").
- A hand-rolled executor. The tokio migration superseded that decision.
- Buffer Device Address re-pointing. Growth re-binds descriptor sets instead (AR-0101).
- Non-coherent memory with hand-issued flush and invalidate. vulkano's guarded access already
  flushes and invalidates non-coherent memory, and the raw-pointer path is taken only when the
  memory is coherent.
- One workgroup per joint instance with threads over the AD lanes. The kernels run one
  invocation per row with the 24 lanes vectorised in `vec4`, which the measurements in the
  document were taken against.
- The north-star move of all local physics into shaders, and any renderer or game content.
